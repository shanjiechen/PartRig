# 2026-09-30

## 项目技术栈梳理（用户提问：用什么技术做的？人物怎么画的？有没有 3D？）

结论：**纯 TypeScript + Vite，Canvas 2D 软件渲染，零运行时依赖，无 Three.js / 无 WebGL / 无任何 3D 引擎和第三方素材。**

- 依赖只有 devDependencies：typescript ^5.6、vite ^5.4。`node_modules` 里仅 vite/rollup/esbuild/typescript/postcss。
- 无框架（无 React/Vue），UI 为 `main.ts` 手工 `innerHTML` + document 级事件委托。
- 素材：**零图片资源**，角色全部由代码生成（`.shots/` 只是开发期截图，不在构建产物里）。

### 渲染管线三层
1. 数据/驱动层 `core/animation.ts` + `anim/clips.ts`：关键帧 JSON → Catmull-Rom(`spline`) 或缓动(`ease`) 采样 → `blendPose` 切换动作时 0.2s 过渡。共 11 个动作片段（待机/行走/奔跑/捅刺/劈砍/射击/施法/使用/受击/打招呼）。
2. 几何层 `core/skeleton.ts`：16 根骨骼（root/pelvis/chest/head + 四肢各 3 段），`solveRig()` 做正向运动学；`core/math.ts` 是自写的 3×3 矩阵/Vec3 库（只有 60 行）。
3. 绘制层 `render/*` + `parts/*`：Canvas 2D 路径绘制 + 画家算法深度排序。

### 核心技术要点（后续改动要记住）
- **伪 3D / 2.5D**：骨骼是真 3D（y 向上、z 朝观众），`projectWorld()` 用正交投影压成 2D，`CAM_PITCH = 0.22`（俯角 ≈12.6°）。投影后保留 z 作为深度。
- 深度排序在 `render/character.ts` 的 `prims[]`：每个部件带 z，`prims.sort((a,b)=>a.z-b.z)` 由远及近。手臂与头部的前后关系由 `vsHead()` 拿关键点与头部球面求交判断。
- **头部球面贴花**（`render/context.ts`）：`surf(a,v)` 球面参数化取点、`cyl()` 柱面、`decal()` 贴花。朝向因子 `f = cos(a + h.yaw)` 决定是否可见 (`f < min` 跳过) 与横向透视收缩 `scale = max(minScale, f^pow)`，pow 常取 0.6。眼/眉/腮红/胎记/耳朵/发簇共用这套方位角-纬度参数，所以八方向转身不会穿帮。
- **八方向**不是 8 套贴图，而是整体 `rotY(yaw)` 旋转；`DIRECTIONS` 定义 8 个 yaw。
- 配色系统 `core/color.ts`：`mix`/`shade`(亮暗)  + **`ink(fill)` 由填充色推导描边色**——卡通风描边一致性的关键。
- 卡通渲染手法：描边用 `ctx.stroke` 且 `lineJoin/lineCap = 'round'`；共线胶囊肢体先统一描边一遍再填色，避免关节处接缝（`drawLimb`）；阴影/高光用 `shade()` 派生而非贴图。
- 导出：`toBlob` 导出精灵图 PNG，按行 8 方向、按列动画帧。
- 开发钩子 `window.__sprite.at(clipId, time, dir)` / `.set(parts)`，仅 DEV 生效，用于浏览器复现精确帧（`.shots/` 里的截图就是这么来的）。

### 部件系统
`parts/index.ts` 定义 14 个槽位（脸型/耳朵/眉毛/眼睛/鼻子/嘴巴/胡子/面部特征/发型/头饰/上装/下装/鞋靴/手持物），每个部件是纯数据定义 + 绘制函数，`resolveParts()` 按 `Appearance` 解析。
